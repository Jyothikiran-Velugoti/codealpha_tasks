
# CodeAlpha Task 1 - Web Scraping & Book Data Analysis

## Project Overview

A Python-based web scraping and data analysis project developed as part of the CodeAlpha Data Analytics Internship.

## Technologies Used

- Python
- BeautifulSoup
- Pandas
- Matplotlib
- Seaborn

## Project Workflow

1. Scraped book information from a website using BeautifulSoup.
2. Extracted and cleaned the collected data using Pandas.
3. Performed price and rating analysis.
4. Generated data visualizations using Matplotlib and Seaborn.
5. Derived basic statistical insights from the dataset.

## Project Structure

- `data/` – Scraped dataset
- `src/` – Python source code
- `charts/` – Generated visualizations
- `requirements.txt` – Required Python libraries
