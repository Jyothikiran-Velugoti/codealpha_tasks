# 📊 Netflix Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project analyzes the Netflix Movies and TV Shows dataset using Python. The objective is to perform Exploratory Data Analysis (EDA), clean the data, visualize trends, and derive meaningful business insights.

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib

## 📂 Project Structure

```

├── requirements.txt
└── README.md
```

## 📈 Analysis Performed
- Dataset Overview
- Missing Value Analysis
- Duplicate Removal
- Movies vs TV Shows
- Top 10 Countries
- Content by Release Year
- Ratings Analysis
- Business Insights

## 📊 Generated Charts
- Movies vs TV Shows
- Top 10 Countries
- Content by Year
- Content Ratings

## 💡 Business Insights
- Movies dominate the Netflix catalog.
- The United States contributes the highest number of titles.
- Netflix content has grown rapidly after 2015.
- TV-MA is one of the most common content ratings.
- Netflix has expanded globally over the years.
