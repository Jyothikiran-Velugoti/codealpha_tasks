# CodeAlpha Task 3 - Data Visualization

## Project Overview

This project was completed as part of the CodeAlpha Data Analyst Internship.

The project focuses on visualizing the Netflix Movies and TV Shows dataset using Python to identify patterns, trends, and meaningful insights.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn

## Project Workflow

1. Loaded and explored the Netflix dataset.
2. Prepared the data for visualization.
3. Created visualizations to analyze Netflix content trends and patterns.
4. Interpreted the visualizations to derive meaningful insights.

## Project Structure

- `Data/` – Dataset used for analysis
- `Charts/` – Generated visualizations
- `Visualization.py` – Python visualization script
- `insights.md` – Key insights from the analysis
- `requirements.txt` – Required Python libraries
